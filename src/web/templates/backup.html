📦 一键备份

本工具内的本地备份流水线 · 扫描 → 解密 → 迁移媒体 → 构建索引 · 默认增量

首次必做：请用本页的「开始备份」

这是 WeChat Export 平台内的一键备份，用来解密并生成本地可读数据； 不是微信客户端里「设置 → 聊天 → 备份与恢复」的官方备份。

  • 微信自带备份无法被本工具直接读取，走错入口会白等。
  • 请先点下方「自动检测」确认数据目录，再点「开始备份」。
  • 备份可在后台继续；离开本页后右上角会显示进度，随时可回来查看。
1

确认微信数据目录

自动检测本机账号；多账号时点选即可填入

💡 找不到时点「深度搜索」（最长 45 秒）；或在微信「设置 → 文件管理 → 打开文件夹」里查看， 把 xwechat_files\<账号>\db_storage 粘贴后点「使用该目录」。
2

设置备份范围

日期与增量选项 · 输出目录可留空自动生成

首次建议备份全部；数据量大时可能较慢

每次写入时间戳目录，可之后在 备份版本 对比 / 回滚，或设置 每天增量定时任务。

3

开始备份

任务在后台异步执行，可切换到其他菜单，完成前右上角会显示进度

① 扫描账号 → ② 解密数据库 → ③ 迁移媒体 → ④ 构建索引
等待开始...

✓ 备份完成
